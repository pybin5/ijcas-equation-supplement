# ijcas-equation-supplement
This repository supports detailed formula explanation for the paper "Heel Strike Modeling and Control Approach for an Omnidirectional Wheeled Mobile Robot".


## Appendix_A.md

### Appendix A. Lagrange Equation for Nominal and Detailed Plant

This page provides the detailed derivations of the Lagrange equation corresponding to Eq. (18) for the **nominal** and **datailed** plant presented in the paper.


## Appendix_B.md

### Appendix B. Reference Trajectory in Simulation

This page provides the detailed derivations of the reference trajectory input to the simulation presented in the paper.
